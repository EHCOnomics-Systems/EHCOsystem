## Verification discipline

For a deeper review, identify the exact proposition first, then inspect the evidence class that can establish it. A repository commit, test fixture, container image, deployment record, or Runtime receipt should not be substituted for another evidence class simply because it is convenient.

The detailed Runtime/repository/test-estate interpretation is centralized in the [canonical boundary record](../architecture/runtime-repository-and-test-estate-boundary.md).
