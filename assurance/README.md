# Public Assurance

This directory maps selected public technical propositions to the records and proof ceilings that support them.

## Current records

- [Ecosystem Claim → Evidence Matrix](ECOSYSTEM-CLAIM-EVIDENCE-MATRIX.md) — technology-estate-wide claim/evidence map with estate lane, bounded claim, current maturity posture, evidence class, public reference, verification method, source-review date, and proof ceiling.
- [EHCO AI-OS Claim → Evidence Matrix](CLAIM-EVIDENCE-MATRIX.md) — focused Tier One claim/evidence map.

## Interpretation rule

Every claim remains within the evidence class and proof ceiling of its cited source. Architecture, accepted standing projection, source acceptance, artifact identity, declaration presence, test design, qualification, bounded observation, build/artifact evidence, release, deployment, production verification, and Runtime evidence are distinct classes and are not interchangeable.

Estate lane is also separate from maturity. The principal shared spine, research/foundation estates, ordinary downstream governed application expansion, and substantial project/pilot programs retain component-specific maturity and evidence. Grasp Safety and Pegasus IT remain downstream governed components even though the public completion model tracks them outside the public core-completion denominator.

The current qualitative maturity posture is not a universal percentage: it states that the foundational/shared EHCOsystem spine is substantially established while remaining work is increasingly concentrated rather than foundational where current owning sources support that conclusion.

For the shared Runtime/repository/test-estate interpretation, use the [canonical boundary record](../architecture/runtime-repository-and-test-estate-boundary.md).
