## Interpretation rule

Every claim remains within the evidence class and proof ceiling of its cited source. Architecture, accepted standing projection, artifact identity, declaration presence, test design, bounded observation, build/artifact evidence, deployment, and Runtime evidence are distinct classes and are not interchangeable.

For the shared Runtime/repository/test-estate interpretation, use the [canonical boundary record](../architecture/runtime-repository-and-test-estate-boundary.md).
