# EHCO AI-OS Public Assurance

This directory maps selected public EHCO AI-OS claims to the public records and proof ceilings that support them.

It is an assurance and navigation surface. It is not the Runtime, does not create Runtime authority or standing, and does not promote repository evidence into Runtime-originated proof or independent certification.

## Current records

- [Claim → Evidence Matrix](CLAIM-EVIDENCE-MATRIX.md)

## Interpretation rule

Every claim must remain within the evidence class and proof ceiling of its cited source. A source may establish architecture, standing projection, artifact identity, declaration presence, bounded observation, package integrity, or another stated property without establishing a different proof class.

The accepted EHCO AI-OS standing remains **52/53**. This directory does not calculate or alter standing.
