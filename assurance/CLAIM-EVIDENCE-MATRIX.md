## Reading the matrix

Each row identifies the proposition, owner, evidence class and scope that establish it. Runtime-originated records remain the controlling evidence class for Runtime state, consequence, persistence, recovery, release and proof. Owning Docker/host evidence remains the controlling evidence class for physical execution observations. Current Full Flex evidence is the public synthesis and routing layer across those relationships.
