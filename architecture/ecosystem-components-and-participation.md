## Runtime relationship rule

A component's mature capability does not by itself establish Tier One Runtime participation. Runtime participation is a separate relationship established only by its owning Runtime evidence. Conversely, absence or later status in that separate dimension does not demote the component capability, artifact, release, staging, or application state already established in its own evidence class.
