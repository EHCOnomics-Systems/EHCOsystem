# Proof and Status Classes

The EHCOsystem records distinct technical, evidentiary, source, build, integration, Runtime, and release states across the public estate.

## Core classes

### Instantiated and demonstrated

A governed relationship has been realized and evidenced through the EHCO system estate, including the accepted Runtime Foundations, proof packets, source bindings, continuity controls, live captures, or Runtime-originated proof.

### Instantiated with protected implementation

The governed relationship is established in the controlled EHCO estate while implementation details remain protected from public disclosure.

### Source accepted

Canonical source identity, ownership, revision, merge, or repository-control state has been accepted through the governing source estate.

### Build verified

A bounded build, test, lint, typing, artifact, security, image, or workflow result has been verified for the identified source revision.

### Integrated and under final closure

Accepted components and source states are being completed through the governing closure plans, gap ledgers, source reconciliation, participation alignment, RAG alignment, portability, lifecycle, and release controls.

### Runtime admitted

A participant, component, or operation has entered the instantiated Runtime through the governing admission and binding relationships.

### Runtime evidenced

The instantiated Runtime has produced the authoritative operational state, receipt, proof, persistence, release, revocation, recovery, or consequence evidence for the governed operation.

### Publicly evidenced

Public-safe dossiers, proof packets, manifests, receipts, source bindings, live captures, verification records, or release artifacts establish the stated public proof range.

### Publicly released

An artifact has been published through the canonical EHCOnomics public record with its version, manifest, checksum, and release identity.

## Evidence relationships

The public estate preserves the relationship among:

- source identity;
- accepted source state;
- build and test evidence;
- integration state;
- Runtime admission;
- Runtime-originated evidence;
- public proof;
- public release.

Each record carries the status established by its owning source, control, evidence, Runtime, or release record.
