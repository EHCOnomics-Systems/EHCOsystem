# EHCOsystem

**Public architecture, research, and publication repository for instantiated AI governance.**

The EHCOsystem is an architectural approach to AI governance built around one governing premise:

> **AI governance begins when valid authority is instantiated before intelligence acts. It becomes end-to-end governance only when every consequential participant and transition preserves the authority, state, evidence, and consequence relationships appropriate to its role.**

This repository documents the public architecture, governing distinctions, research lineage, evidence classes, and publication-safe materials associated with that work.

## What this repository contains

- The immutable Runtime baseline
- The later ecosystem-governance discovery
- Public definitions and proof classes
- Publication-safe architectural documentation
- Public EHCO research lineage
- External references and incident analysis
- Controlled-review and evidence-boundary policies

## What this repository does not contain

This repository does **not** contain the proprietary EHCO Runtime, private participant implementations, Instantiation Bridge mechanics, internal control anchors, source code, schemas, verifier logic, deployment topology, credentials, endpoints, proof packets, private evidence records, or production infrastructure.

Public materials describe the governed properties, architectural distinctions, evidence classes, and proof ceilings. Confidential implementation evidence is maintained separately and may be made available only through controlled review.

## Core distinctions

- Capability is not authority.
- Permission is not standing.
- A proposal is not a disposition.
- Execution is not authorization.
- Evidence is not proof.
- Testing is not deployment.
- Deployment is not admission.
- Generation is not Runtime recognition.
- A ledger is evidence, not authority.
- A dashboard is projection, not Runtime truth.
- Observation and scope miss do not create state change.
